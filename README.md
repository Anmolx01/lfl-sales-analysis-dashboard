# Like-for-Like Sales Analysis Dashboard

## Overview

A Power BI dashboard developed during my Data Analytics internship at DataMelon Labs to analyze Like-for-Like business performance for 2026 compared with 2025.

The dashboard evaluates sales, transactions, average transaction value, quantity, regional performance, departments, categories, cities, and store formats.

## Key Features

- 2026 vs 2025 sales comparison
- Like-for-Like sales growth analysis
- Transaction growth analysis
- Average Transaction Value analysis
- Quantity growth analysis
- Regional performance
- City and store-format analysis
- Department performance
- Category performance
- Monthly sales trends
- Store-format contribution
